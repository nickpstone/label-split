# Label workspace
Mode: Operate. One recurring task: drop daily PDF, verify labels, print.
## Direction contract
THESIS: A compact print workbench with source, layout, and a clear output preview; avoid a marketing landing page.
OWN-WORLD: Cool light-gray canvas, white work surface, deep navy ink, muted blue secondary text and a cobalt action. System sans, 16px body, 32px page title. Fine borders and small functional radii.
STORY: Upload an A4 sheet, see the detected six labels, select paper size, download or print at actual size.
FIRST VIEWPORT: Simple brand bar; task title and local-processing note; a narrow setup column beside a large preview pane. Empty preview shows a real HTML paper-layout diagram with accessible text. The primary upload action is first; export controls appear only once ready.
FORM: A print workbench, code-first; seed: none (unavailable).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
